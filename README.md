# MD. Monir Hossain — Civil Engineer Portfolio

Responsive static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website sections and content
- `style.css` — blue/white civil engineering theme and responsive design
- `script.js` — mobile menu and footer year
- `cv.pdf` — starter CV PDF download

## Publish with GitHub + Vercel
1. Extract this ZIP.
2. Create a GitHub repository, e.g. `monir-civil-portfolio`.
3. Upload the files inside this folder directly to the repository root.
4. Open Vercel → Add New → Project, import the repository, then Deploy.
5. This is a static site; no build command is required. Keep defaults or set the output directory to `./`.
6. After deployment, share the public URL.

## Before sharing
Update the phone/email in `index.html`, add a photo if desired, and verify experience dates and project/employer names. Replace `cv.pdf` with your final CV PDF if you already have a preferred version. The included CV is a starter draft and does not invent contact details or employer names.
